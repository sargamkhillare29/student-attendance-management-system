
# Student Attendance Management System

## About the Project

The Student Attendance Management System is a web-based application developed to manage and track student attendance digitally.

The system helps manage student records, mark attendance, and view attendance records.

## Features

- User login system
- Admin dashboard
- Student management
- Teacher management
- Attendance marking
- Attendance records
- Student attendance history
- Logout system

## Technologies Used

- PHP

- HTML
- CSS
- JavaScript
- XAMPP

## How to Run the Project

1. Install XAMPP.
2. Start Apache and MySQL from the XAMPP Control Panel.
3. Place the project folder inside the XAMPP `htdocs` folder.
4. Create the required MySQL database.
5. Import the database tables.
6. Check the database connection in `includes/db.php`.
7. Open the project in a web browser through localhost.

## Project Purpose

The purpose of this project is to replace traditional manual attendance recording with a digital attendance management system.
